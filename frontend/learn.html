    How Learn mode works

    1. Read the notebook on the right, like in Colab.
    2. Cells with a ◧ Visualise button contain a circuit. Click it and the circuit appears in the middle.
    3. Play: pick a gate on the left, click a wire slot. Click a placed gate to see its matrix and the state after it.
    4. Run to see the measurement distribution. The Qiskit code tab always shows the matching code — copy it into Colab.

    Your notebook is never edited. The canvas is a sandbox next to it.
